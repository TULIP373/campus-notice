# 课程通知平台规格
## 目标和事实出处
学生按课程查找教师通知、提交要求、格式、截止时间与学习资料，减少翻找零散消息。用户2026-10-08请求优先于课程建议；原始课程方案个人实验部分决定五实验步骤（摘录见docs/teacher-steps.md）；原始实验报告参考模板00931.doc决定报告样式。功能和数值只在本规格定义，验收以docs/acceptance.md为准。
## 功能
Java Entity/Mapper/Service/Controller 分层，真实MySQL。实验一用户CRUD，实验四再加BCrypt/JWT/Spring Security。数据库用户、角色、权限及关联表、课程、通知。教师维护用户、课程通知；学生查看。通知包含课程、标题、正文、提交要求、报告格式、截止时间、来源、类型（通知/资料）。Vue+Axios真实REST JSON，课程与关键词筛选、详情、三门演示课，每课有通知与资料，明确标为演示。
实验四令牌有限期，前端只保存在内存；@PreAuthorize控制教师维护；401/403与验证错误可区分。密码只存BCrypt，签名密钥仅本地文件或环境变量。示例账户初始化脚本生成密码哈希。
实验五课程资料切块450字重叠80字，中文字符片段TF-IDF稀疏向量，余弦检索前三块，课程过滤，System/User提示拼接、模型调用和原文引用。输入1至1000字，缺少相关资料拒绝编造；防提示注入并验证引用。真实模型不可用则明确报错，禁止固定答案冒充模型。
