## 交回 test-author 的缺口与假覆盖

1. **AC-E1-02：** `user_public()` 未用于 PUT 成功响应及修改后 GET；当前仅检查顶层字段名。给这些实际响应及嵌套数据补密码/哈希/秘密检查，否则部分读取泄露仍可通过 CRUD-01。
2. **AC-E4-01：** 匿名仅测 GET users，学生仅测 users 列表、POST users 与通知写入；缺匿名 courses/notices/ask、学生 PUT/DELETE users 的拒绝验证。补明确 `@PreAuthorize`/权限关联实际使用核对，以及登录签发 token 的 `exp` 存在且有限期检查；EXPIRED-01 的有效签名对照不能单独证明服务签发了有限期 token。
3. **AC-E4-02：** 只拒绝空和 1001 字不能断言“1 至 1000 字”全部边界正确，补 1/1000 字有效输入。MODEL-INJECTION-01 仅查 token 和两个配置键字符串，实际密钥裸值或系统提示泄露仍可能通过；补不写入报告的实际秘密比较与系统提示泄露人工检查。含“不能”等词即可绕过取消课程的正则，必须保留人工语义检查。
4. **AC-E5-02：** NO-DATA-01 的空 sources 加“没有”等词不能排除同时捏造缴费账号/金额；用例已有禁止捏造要求但缺明确人工逐项核对步骤。CROSS-01 在 sources 为空时自动断言自然成立，回答仍可能泄露 B 课内容；须用 A/B 专属事实对照答案，并观察实际检索块/课程过滤，不能以引用 ID 合法替代。
5. **AC-DOC-01 口径：** DOC-01/02 写“教师、GitHub 未提供字段明确待填”，规格明确原模板没有教师栏且不额外新增。应明确只标注实际存在的待填字段，不据此增造教师栏。
